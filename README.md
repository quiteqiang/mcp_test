# mcp_test

This project explores the Model Context Protocol (MCP), a standard that allows AI models like Claude to interact with external tools and services.

MCP enables Claude to perform real-world actions — such as managing GitHub repositories, searching code, and handling issues — directly from the conversation without switching to a browser.

## Files

### snake.html

A classic Snake game built with vanilla HTML, CSS, and JavaScript. Open it in any browser to play.

- **Space** — start / restart
- **Arrow keys** — control direction
- Eat food to grow and earn 10 points per piece; hitting a wall or yourself ends the game.
